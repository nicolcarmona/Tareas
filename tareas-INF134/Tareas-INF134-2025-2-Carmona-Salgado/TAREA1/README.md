## Caracteristicas de funcionamiento

El codigo busca facilitar la manipulación de información sobre datos de estudiantes cursantes de distintas materias, todo esto accesible gracias a un menú de opciones.

### Como funciona :
Primeramente traducimos un archivo binario con los datos a revisar y corregimos los errores para trabajar cómodamente con ellos.

Luego con desplegar un menú de opciones, según cual sea la seleccionada, se hará llamado de una de las distintas funciones trabajadas dentro del codigo así cumpliendo la petición del usuario. 

Esto lo cumple pidiendo, de ser necesario, información adicional por la consola.


### Compilación del Codigo :
Compilamos el codigo directamente con g++ haciendo llamado en la terminal de VsCode. 

- " g++ archivo.cpp -o tarea1 -Wall "
